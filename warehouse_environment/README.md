# Warehouse environment

The environment contains a 18 x 15 m warehouse, boundary walls, three rack banks, six overhead point lights, safety barriers, eight lightweight packages, three destination zones, a charging station and a pickup/loading zone.

Every package is 0.45 x 0.35 x 0.30 m and has a large `BOX 101`-style label plus a QR code containing the same numerical ID. The label is a texture attached to the front face so the robot camera can see it.

The supplied robot description does not contain a real gripper or a rated payload specification. Therefore the box dimensions/weights are conservative simulation values rather than a claimed hardware payload rating. A front pickup tray has been added to make the approach geometry explicit.
